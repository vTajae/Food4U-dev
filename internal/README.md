# internal/ — private development material

Nothing in this folder is published. The public repository `vTajae/Food4U` receives only the paths listed in `prod-allowlist.txt` (used by the promotion tool), and `internal/` is never on that list.

| Path | What it holds |
|---|---|
| `history/` | 2024 hackathon notes, API research, early schema drafts and diagrams |
| `sprint/` | Sprint 1 plans, reports and screenshot evidence (October 2026) |
| `upgrade-plan.md` | The architectural blueprint and business strategy |
| `runbooks/` | Owner-only operational runbooks that name infrastructure identifiers |
| `prompting/` | Prompt drafts and example data |
| `reference/` | Third-party reference material kept for the safety-layer design |
| `e2e/DEFECTS.md` | The exploratory defect register that the e2e `fixme` IDs point to |
| `STATUS.md` | Current state and next action for whoever picks the work up |

Personal context, strategy, credential locations and internal tool narration belong here, never in `docs/`.
